## PART 4: TECHNICAL SEO ROADMAP

### Phase 1: CRITICAL — Migrate to Server-Side Rendering (Week 1-3)

**The single most important change.** Your React SPA cannot rank on Google. You MUST move to a framework with SSR/SSG.

**Recommended: Migrate to Next.js**
- Server-side rendering (SSR) means Google can crawl every page
- Static generation (SSG) for content pages = fastest possible load times
- Built-in sitemap generation, robots.txt, meta tags per page
- API routes (replace your current /api/ functions)
- Image optimization built in
- Keep your existing React components, Tailwind, shadcn/ui

**Migration path:**
1. Create new Next.js project with App Router
2. Port existing React components as-is (they'll work)
3. Convert pages to Next.js page components with proper metadata
4. Move API routes to Next.js API routes
5. Deploy to Vercel (same as now, better performance)

### Phase 2: Technical Foundations (Week 2-3)

After Next.js migration:

1. **robots.txt** — Allow all crawlers, point to sitemap
```
User-agent: *
Allow: /
Sitemap: https://www.assetliftlending.com/sitemap.xml
```

2. **XML Sitemap** — Auto-generated by Next.js, include all pages
3. **Canonical tags** — Every page gets `<link rel="canonical" href="...">`
4. **Proper favicon** — Add .ico and .svg versions + web manifest
5. **www redirect** — Pick one (www or non-www) and 301 redirect the other
6. **HTTPS enforcement** — Ensure all URLs are HTTPS
7. **Page speed** — Target 90+ on all Core Web Vitals
8. **Mobile-first** — Already good, verify with Google's mobile test
9. **Breadcrumb schema** — Add to all pages
10. **Image alt text** — Descriptive alts on all images

### Phase 3: On-Page SEO Structure (Week 3-4)

Every page needs:
- Unique `<title>` tag (50-60 characters) with primary keyword
- Unique `<meta description>` (150-160 characters) with CTA
- One `<h1>` per page with primary keyword
- Logical heading hierarchy (H1 > H2 > H3)
- Internal links to related pages
- Schema markup appropriate to page type
- Open Graph tags
- Clean, keyword-rich URL slug
